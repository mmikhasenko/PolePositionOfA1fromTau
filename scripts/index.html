Script map

Run julia +1.13 --project=. scripts/NAME.jl from the repository root. Data paths are resolved from the script location. Add --smoke for smaller grids or fewer replicas. The full grid and bootstrap jobs are deliberately opt-in; their smoke variants are exercised in CI. common.jl is shared support, not a standalone job. Outputs default to artifacts/.

Migration from 2018

The original interactive worksheets are preserved in commit e508486. Their names under tests/ remain wrappers; pole_invesrigation.jl forwards to the corrected spelling. Undeclared session variables, interactive widgets, and private paths have been replaced by explicit jobs. The bootstrap driver exports parameter replicas; it does not recreate the old unverified pole-bootstrap plots. The radius scan exports fixed-parameter shape variations, not the old manually edited mass/width refit study. These scopes are explicit so smoke checks cannot be mistaken for a reproduction of all paper fits.
