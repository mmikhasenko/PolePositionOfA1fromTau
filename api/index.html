API

PolePositionOfA1fromTau.Dispersive.DispersiveLineshape — Type
DispersiveLineshape(rho; threshold, subtraction, rtol=1e-7)

Construct a once-subtracted three-body self-energy model for use in a Breit–Wigner-like amplitude. Its real part is obtained from a dispersion integral over the supplied spectral density.

Parameters

  • rho: callable real, dimensionless spectral density rho(x), supported above threshold; x is an invariant mass squared in GeV². For the paper's symmetrized a₁ → ρπ model, use the density prepared by JPACModel.density(:symm).
  • threshold: positive lower integration limit in GeV² (physically 9mπ²).
  • subtraction: squared energy in GeV² where Re Π(subtraction+i0)=0.
  • rtol: positive relative quadrature tolerance; does not control density interpolation error.

The density must be continuous, piecewise differentiable, and grow slower than x at infinity. Construction evaluates the real subtraction constant. JPACModel.dispersive_model(:symm) prepares and caches the physical model.

Example

julia> using PolePositionOfA1fromTau

julia> model = DispersiveLineshape(x -> 1.0; threshold=0.2, subtraction=0.6);

julia> abs(real(selfenergy(model, 0.6))) < 1e-10
true

The constant density in this example is an analytic benchmark, not a₁ phase space.

PolePositionOfA1fromTau.Dispersive.selfenergy — Function
selfenergy(model, s; sheet=:I, continued_density=nothing)

Return the dimensionless subtracted loop Π(s), with Im Π(s+i0)=model.rho(s).

Parameters

  • model: a DispersiveLineshape, including the density and subtraction.
  • s: real or complex three-pion invariant mass squared in GeV². A real argument denotes the upper rim of the physical cut.
  • sheet: :I for the dispersive first sheet, or :II for its continuation into the adjacent lower-half-plane sheet (requires imag(s)<0).
  • continued_density: callable holomorphic continuation of the density, required for :II; its contour and branch history must be supplied by the caller.

On sheet II the returned loop is ΠI(s)+2im*continued_density(s). The dispersion integral fixes the first sheet; it does not by itself certify complex Dalitz-contour transport to a resonance pole.

Example

julia> using PolePositionOfA1fromTau

julia> model = PolePositionOfA1fromTau.JPACModel.dispersive_model(:symm);

julia> isapprox(imag(selfenergy(model, 1.2)), model.rho(1.2))
true

PolePositionOfA1fromTau.Dispersive.amplitude — Function
amplitude(model, s, m, g; sheet=:I, continued_density=nothing)

Return the dimensionless Breit–Wigner-like amplitude t(s) = g²/(m²-s-g²Π(s)/2). For the symmetrized model, Π includes the Dalitz-integrated a₁ → ρπ → 3π decay chains and their interference.

Parameters

  • model: a DispersiveLineshape specifying the self-energy.
  • s: three-pion invariant mass squared in GeV²; real values mean the upper rim.
  • m: bare resonance mass parameter in GeV, not the extracted pole mass.
  • g: coupling in GeV for the dimensionless spectral-density convention.
  • sheet, continued_density: passed to selfenergy.

Example

julia> using PolePositionOfA1fromTau

julia> model = PolePositionOfA1fromTau.JPACModel.dispersive_model(:symm);

julia> t = amplitude(model, 1.2, 1.3, 7.0); # illustrative m and g

julia> isapprox(imag(inv(t)), -model.rho(1.2)/2)
true

PolePositionOfA1fromTau.Dispersive.intensity — Function
intensity(model, s, m, g, normalization=1; mtau=1.776)

Return the real-axis tau-decay spectrum |normalization*t(s)|² rho(s) (mtau²-s)²/s (1+2s/mtau²).

Parameters

  • model: a DispersiveLineshape; its density is also the final-state factor.
  • s: real three-pion invariant mass squared in GeV².
  • m, g: bare resonance mass and coupling in GeV, as in amplitude.
  • normalization: overall production-amplitude normalization (default 1); its modulus squared scales the spectrum and determines its overall units.
  • mtau: tau mass in GeV (default 1.776, the historical model value).

Returns zero outside model.threshold < s < mtau². This is a spectrum, not a probability density normalized to unit integral.

Example

julia> using PolePositionOfA1fromTau

julia> model = PolePositionOfA1fromTau.JPACModel.dispersive_model(:symm);

julia> intensity(model, 1.2, 1.3, 7.0, 1.0) > 0 # illustrative parameters
true

PolePositionOfA1fromTau.JPACModel.qtb — Function
qtb(s)
qtb(s::Complex, rr=1.0)

Return the dimensionless quasi-two-body a₁ → ρπ spectral density, integrating one normalized rho-isobar decay chain over three-pion phase space. Interference between the symmetrized decay chains is omitted; see symm.

s is the total three-pion invariant mass squared in GeV². For real s, the result vanishes at and below 9mπ². The fixed pion/rho masses, rho width, and barrier radius are defined in Masses and Isobars. For complex s, optional rr scales the real part of the historical outer contour waypoint; rr <= 0 selects the direct path. This is a contour parameter, not a physical model parameter or a guarantee of the intended sheet.

Example

julia> using PolePositionOfA1fromTau

julia> qtb(1.2) > 0 # s in GeV²
true

PolePositionOfA1fromTau.JPACModel.interference — Function
interference(s::Float64)
interference(s::Complex, rr=1.0)

Return the dimensionless additive interference contribution from the two rho-pion decay chains integrated over the Dalitz plot: symm(s) = qtb(s) + interference(s). Its sign is the opposite of the term called ρ_INT in the paper. The interference alone need not be positive.

s is the three-pion invariant mass squared in GeV². Use a Float64 for physical real-axis evaluation; the result is zero at and below 9mπ². For complex s, rr scales the real part of the outer contour waypoint; rr <= 0 removes that bend. The complex method retains the historical contour prescription discussed in the addendum; its global sheet transport is not certified.

Example

julia> using PolePositionOfA1fromTau

julia> isapprox(qtb(1.2) + interference(1.2), symm(1.2))
true

PolePositionOfA1fromTau.JPACModel.symm — Function
symm(s)
symm(s::Complex, rr=1.0)

Return the dimensionless a₁ → ρπ → 3π spectral density symmetrized over the decay Dalitz plot, including interference: qtb(s) + interference(s). This supplies the absorptive part of the symmetrized dispersive lineshape.

s is the total three-pion invariant mass squared in GeV²; use Float64 for the physical real-axis density. The optional complex-contour parameter rr is forwarded to qtb and interference; consult their contour limitations before using complex energies. For repeated real-axis lineshape evaluation, JPACModel.dispersive_model(:symm) caches the density table.

Example

julia> using PolePositionOfA1fromTau

julia> symm(1.2) > 0 # physical three-pion spectral density
true
