API

PolePositionOfA1fromTau.Dispersive.DispersiveLineshape — Type
DispersiveLineshape(rho; threshold, subtraction, rtol=1e-7)

Once-subtracted dispersive model for a real spectral density rho(x) supported above threshold. All energy arguments are squared energies in GeV². The real part of the self-energy vanishes at subtraction. The density must be continuous, piecewise differentiable, and grow slower than x at infinity. See the generated equations page for normalization and sheet conventions.

source
PolePositionOfA1fromTau.Dispersive.selfenergy — Function
selfenergy(model, s; sheet=:I, continued_density=nothing)

Return Π(s), with Im Π(s+i0)=rho(s). A real argument means the upper rim. For sheet=:II, supply a holomorphic continued_density(s) with the intended contour history; ΠII=ΠI+2i*rho_cont is the adjacent-sheet formula below the cut. No principal-root continuation of a physical squared amplitude is inferred.

PolePositionOfA1fromTau.Dispersive.amplitude — Function
amplitude(model, s, m, g; kwargs...)

Return g²/(m²-s-g²Π(s)/2), with m and g in GeV for a dimensionless density. Keyword arguments are passed to selfenergy.

PolePositionOfA1fromTau.Dispersive.intensity — Function
intensity(model, s, m, g, normalization=1; mtau=1.776)

Tau-decay spectrum |normalization*t(s)|² rho(s) (mtau²-s)²/s (1+2s/mtau²). Returns zero outside the physical interval. Overall units depend on normalization.
